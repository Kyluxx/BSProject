# 🏨 Hotel Reservation - UI Elegan & Simpel  

🚀 **Sistem reservasi hotel dengan tampilan modern dan minimalis**  
✨ **Menggunakan tema putih & biru untuk pengalaman booking yang nyaman**  

## 📌 Fitur  
- 🎨 **Desain Minimalis & Modern** - UI Simple tapi modern
- 🏨 **Antarmuka yang Nyaman Dipandang** – Warna netral & kontras yang pas  
- ⚡ **Ringan & Cepat** – Optimasi tanpa framework berat  

## 🛠️ Teknologi yang Digunakan  
- **Frontend:** HTML, CSS  
- **Framework:** Pure CSS (Tanpa Framework)
- 
## 📦 Instalasi  
Clone repository ini ke lokal:  
```
git clone https://github.com/Kyluxx/BSProject/
cd BSProject
```
Start PHP Server 
```
php -S 127.0.0.1:3000
```
Buka 127.0.0.1:3000 di browser untuk melihat tampilan.
